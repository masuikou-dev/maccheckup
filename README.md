# MacCheckup

MacCheckup は、macOS の基本情報とディスク・メモリ・バッテリーの状態を確認し、専門知識がない人にも読みやすい Markdown レポートを表示する小さな OSS プロジェクトです。

> **開発初期版 (0.1.0)** — 故障を診断するツールではなく、状態を確認するための目安です。

## 特徴

- macOS 標準コマンドだけで動作
- `sudo` 不要
- ネットワーク通信や外部 API を使用しない
- 設定変更、削除、修復などを行わない読み取り専用設計
- 一部の情報が取得できなくても、可能な範囲でレポートを出力
- Markdown 形式なので、ターミナルで読んだりファイルに保存したりできる

## 必要環境

- macOS
- macOS 標準の Bash 3.2 で動作することを目標にしています

## 実行方法

ターミナルでプロジェクトのディレクトリに移動して、次を実行します。

```bash
chmod +x maccheckup.sh
./maccheckup.sh
```

ヘルプとバージョンを表示するには:

```bash
./maccheckup.sh --help
./maccheckup.sh --version
```

## レポートを保存する

```bash
./maccheckup.sh > maccheckup-report.md
```

保存したレポートは、テキストエディタや Markdown 対応アプリで開けます。共有する前に、個人情報が含まれていないか自分で確認してください。

## 初回セットアップ（ディレクトリ作成から）

以下をターミナルに貼り付けると、作業用ディレクトリと必要なファイルを作れます。

```bash
mkdir -p ~/Projects/maccheckup
cd ~/Projects/maccheckup
mkdir -p tests fixtures/sample-data docs
touch maccheckup.sh README.md LICENSE .gitignore
```

すでに GitHub からクローンした、またはこのプロジェクト一式を展開した場合は、上記のファイル作成は不要です。

## チェック項目と判定ルール

- **起動ディスク:** 空き容量が 10% 未満なら「要確認」、10% 以上 20% 未満なら「注意」、20% 以上なら「正常」と表示します。容量だけで故障を判断するものではありません。
- **メモリ:** macOS の `memory_pressure -Q` から利用可能メモリの目安を読み取ります。10% 未満なら「注意」とします。取得できない場合は「判定不可」です。
- **バッテリー:** バッテリー残量を取得でき、15% 未満なら「注意」とします。残量だけで劣化度は判定しません。デスクトップ Mac など、バッテリーがない機種は「判定不可」と表示します。

数値は初期版の簡易ルールであり、Apple が定める故障判定基準ではありません。

## テスト

macOS 上で次のコマンドを実行できます。

```bash
bash -n maccheckup.sh
./maccheckup.sh --help
./maccheckup.sh --version
./maccheckup.sh
```

Linux など macOS 以外の環境では、`sw_vers` や `pmset` などが存在しないため、診断結果のテストはできません。構文確認は `bash -n maccheckup.sh` で行えます。

## プライバシーと安全性

- シリアル番号、ユーザー名、ホームディレクトリのパスは意図的に取得しません。
- ネットワーク通信は行いません。
- `sudo` を実行しません。
- ファイルの削除、設定変更、修復処理は行いません。
- 共有・公開する前に、レポートの内容を確認してください。

## 制限事項

- このツールは基本的な状態確認であり、ハードウェア故障の確定診断ではありません。
- 空き容量は起動ディスク `/` を対象にしています。APFS の共有容量などにより、表示がディスク全体の状況と完全に一致しない場合があります。
- メモリの値は測定した瞬間の目安です。
- バッテリーの最大容量、充放電回数、SMART 状態、温度、ログ解析などは現時点では対象外です。
- 出力される OS やモデル情報は、実行環境や macOS のバージョンにより取得できない場合があります。
